# 設定資料集エディタ

キャラクター・背景・スチル・（好きな）セクションの設定資料集を、ブラウザで見ながら編集するツールです。
Mac で起動したサーバーに、同じネットワークの iPad や別の PC からつないで一緒に編集できます。

## 起動（Python 3 だけ。追加インストール不要）

```sh
python3 server.py                  # ./project をデータフォルダにして起動
python3 server.py --project ../my-book --port 8000
python3 server.py --token 合言葉     # 外部に公開するときは必ず合言葉を付ける
python3 server.py --tunnel         # cloudflared があれば外部（https）URL も発行
```

`start.sh`（Mac/Linux）または `start.bat`（Windows）をダブルクリックでも起動します。
起動すると次のようなURLが表示されます。

```
このPC        : http://localhost:8000/
同じWi-Fi内   : http://192.168.x.x:8000/   （iPadなどはこちら）
```

### iPad / 他のPCから
同じWi-Fiにつないで、表示された「同じWi-Fi内」のURLを Safari で開くだけです。
画像の追加は「画像ライブラリ → アップロード」（写真アプリからも選べます）。ダブルクリックの代わりに「素早く2回タップ」で編集できます。

### 外から（グローバル）つなぐ
- **Tailscale**（おすすめ・無料）: Mac と iPad に入れると、どこからでも `http://MacのTailscale IP:8000/` で安全につながります。
- **Cloudflare Tunnel**: `python3 server.py --tunnel`（`cloudflared` が必要）。表示された https URL の末尾に `/?t=合言葉` を付けて開きます。
- ルーターのポート開放は非推奨です。公開するときは必ず `--token` を付けてください。

## データの置き場所（gitで管理するフォルダ）

```
project/
  project.json                 プロジェクト名など
  sections/<key>.json          セクション（キャラクター・背景・独自セクション…）
  items/<section>/<item>/item.json
  items/<section>/<item>/<page>.jsonl   1ページ=1ファイル。1行=1要素
  templates/<section>/<id>.jsonl        自分のテンプレート
  images/<section>/<hash>.png           アップロードした画像（セクション別フォルダ）
  images/<section>/<hash>.json          画像の名前・タグ
```

- 画像は **相対パス**（`images/chars/xxxx.png`）で参照されます。フォルダに画像を直接置いても、画像ライブラリに現れます。
- 画像ファイル名は内容のハッシュなので、同じ画像を何人がアップロードしても衝突しません。
- 1ページ=1ファイル、1要素=1行なので、別々のページ・別々の要素を触った変更は git が自動でマージできます。
- ブラウザの `localStorage` / IndexedDB は使っていません。保存先は常にこのフォルダです。

### gitでの使い方
```sh
cd project && git init && git add . && git commit -m "init"
# みんなで共有：リモートを作って push / pull
```
- `git pull` した変更は、開いている画面に数秒で自動反映されます。
- 同じページの同じ行を、同時に別々の人が編集して保存した場合だけ「ぶつかりました」と表示されます。
  「相手の変更を取り込む」か「自分の内容で上書き」を選べます（サーバーのファイルは勝手に上書きされません）。
- `git merge` で本物のコンフリクトが起きたら、`<<<<<<<` の印が入ったファイルを直してください（読み込み時にファイル名を表示します）。

## 主な機能
- **セクション**: 「＋ セクション」で追加／「⚙ 設定」で名前変更・削除。追加すると「表紙・扉」に扉ページも自動追加。
- **差分枠**: 「＋ 差分枠を描く」で範囲をドラッグ → 行・列を指定。あとから「差分枠の設定…」で変更。複数画像のドロップで順に入ります。
- **画像ライブラリ**: フォルダ別・タグ・検索。ドラッグ＆ドロップ、またはタップで挿入。
- **枠のスタイル**: 塗り／塗りなし／実線／破線／点線／二重線／ポラロイド／角トンボ。
- **グループ化（Ctrl+G）**・**スマートガイド**（他の要素の端・中央に吸着）・整列・ロック・透明度・角丸。
- **縦/横**・見開き、テンプレート保存、PDF（見開きは左右分割）、PNG(zip)、プレゼン。

## ショートカット
`Shift+クリック` 複数選択 / `Ctrl+A` 全選択 / `Ctrl+G` グループ / `Ctrl+D` 複製 / `Ctrl+Z` `Ctrl+Y` 元に戻す・やり直し / `Alt+クリック` グループ内の1つだけ選択 / `Esc` 選択解除

## サーバーなしで使う場合
`index.html` を開く（または `python3 -m http.server`）と「サーバー未接続」になり、保存されません。
「サイト書き出し(zip)」で書き出し、「読み込み(zip/JSON)」で戻せます（zipの中身は上のフォルダ構成と同じなので、そのまま `project/` として使えます）。
