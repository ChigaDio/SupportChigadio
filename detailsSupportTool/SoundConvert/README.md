# Sound Ext Converter

サウンドファイルの拡張子(コーデック)を一括変換できるデスクトップGUIツールです。
PySide6(Qt)で実装しており、高速な検索・再生・変換をバックグラウンドスレッドで行います。

## 主な機能

- **作業フォルダの設定**
  - 初回起動時に、フォルダパスを直接入力 or 「📂 選択...」ボタンでエクスプローラーから選択
  - 設定したパスは自動保存され、次回起動時も維持されます
  - 上部の入力欄からいつでも再設定可能(「🔄 再検索」で反映)

- **再帰検索・サブフォルダごとのグループ表示**
  - 指定フォルダ配下を再帰的に検索し、サブフォルダごとにグループ化して一覧表示
  - 各行に「再生ボタン(音量/シークバー付き)」「ファイル名」「サイズ」「現在の拡張子」を表示
  - 一覧は開いたグループのみ再生コントロールを生成する遅延ロードにより、大量ファイルでも軽快に動作します

- **変換方法(3パターンに対応)**
  1. **1ファイルずつ**: 各行の「変換」ボタン
  2. **複数選択**: チェックボックスで選択 →「✓ 選択したファイルを変換」
  3. **サブフォルダごと再帰的に全部**: フォルダ行を右クリック →「このフォルダ以下を再帰的にすべて変換」
  - 表示中の全ファイルを一括変換する「⚡ 表示中すべてを変換」も利用可能
  - 変換先拡張子は OGG Vorbis / MP3 / WAV / Opus からドロップダウンで選択

- **変換中の進捗表示 & 操作ロック**
  - 変換中はオーバーレイに進捗バーとファイル名を表示
  - 変換完了までツリー操作や他ボタンは無効化されます

## 必要環境

- Python 3.9 以降
- **ffmpeg**(拡張子変換に使用。事前にインストールし、PATHが通っている必要があります)
  - https://ffmpeg.org/download.html
  - Windows: `winget install ffmpeg` または公式サイトからダウンロードしPATH追加
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg` など

## セットアップ

```bash
pip install -r requirements.txt
python main.py
```

## ファイル構成

```
sound_converter/
├── main.py             # エントリーポイント
├── main_window.py       # メインウィンドウ・UI・再生/変換制御
├── audio_scanner.py     # 再帰検索(バックグラウンドスレッド)
├── converter.py         # ffmpegによる変換処理(バックグラウンドスレッド)
├── config_manager.py    # 設定(作業フォルダ等)の保存/読込
├── style.qss            # ダークモダンテーマのスタイルシート
└── requirements.txt
```

設定ファイルは `~/.sound_ext_converter/config.json` に保存されます。

## 対応フォーマット

検索対象拡張子: `.mp3 .wav .ogg .oga .opus .flac .m4a .aac .wma .aiff .aif`

変換先: OGG Vorbis(.ogg) / MP3(.mp3) / WAV(.wav) / Opus(.opus)
