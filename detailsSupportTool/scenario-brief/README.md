# シナリオ演出依頼資料集

小説(シナリオ)を元に、演出の指示・メモを書き込んで A4 の PDF にするツールです。ブラウザで使います。

## 起動
- Windows: `run.bat` / Mac・Linux: `./run.sh`（Python 3.8+、追加インストール不要）
- 初回起動時、黒い画面に **初期管理者 `admin` とパスワード** が表示されます。ログイン後、マイページで必ず変更してください。
  （忘れたら `python server.py --admin-password 新しいパスワード` で再設定）
- 同じWi-Fi/LAN内の別PC・iPadからは、黒い画面に表示される `http://192.168.x.x:8765/` を開きます（ユーザー名+パスワードでログイン）。
  このPCだけで使うなら `--local-only`。Windowsは初回にファイアウォール(プライベートネットワーク)を許可してください。

## 実行ファイル化 (PyInstaller)
`build.bat`（Windows） / `./build.sh`（Mac）→ `dist/ScenarioBrief(.exe)`。各OS上でビルドしてください。

## アカウント・プロジェクト・シナリオ
- 構造は **プロジェクト → シナリオ(複数) → 章(複数)** です。プロジェクトページでシナリオを開く（折り畳み）と章が並び、章を選ぶと編集画面に進みます。
- **権限**（管理者はプロジェクト一覧の「👥 権限」、各シナリオの「🔒 権限」から設定。変更はその場で保存）
  - プロジェクト単位: 参加しない / **閲覧のみ** / **閲覧＋メモ**（本文は編集不可、自分のメモ・書き込みは可）/ **編集可**
  - シナリオ単位の詳細: 「プロジェクトに合わせる」/ **閲覧不可** / 閲覧のみ / 閲覧＋メモ / 編集可、および **PDF出力の可否**
  - **閲覧不可のシナリオ（章・書き込み・その章専用の設定資料）は、その人の画面にもAPIにも出ません。** 見られるシナリオが1つもないプロジェクトは、一覧にも出ません。
- シナリオの追加・**名前変更**（✎名前 / タイトルをダブルクリック）・並べ替え・削除は、プロジェクトの編集権限がある人ができます。
- **章の操作**（そのシナリオの編集権限が必要）: 章の左の **⠿ をドラッグ**して並べ替え。別のシナリオの上へドロップすると **そのシナリオへ移動**（閉じているシナリオの上で少し待つと開きます）。章の行の ✎ 章名変更 / ⧉ **複製**（書き込みも複製するか選べます。同じシナリオなら元の章の直後に入ります）/ ➜ 別のシナリオへ移動 / 🗑 削除。移動・複製には、移動元と移動先の両方で編集権限が必要です。
- **設定資料（世界観・用語・キャラクター）はプロジェクト内で共有**されます。各設定の「共有範囲」で「プロジェクト全体で共有（初期値）」「このシナリオだけ」「特定の章だけ」を選べます。プロジェクトページの「📚 設定資料（プロジェクト共通）」からも開けます。閲覧できないシナリオ限定の設定は、その人には見えません。
- ログインした端末は記憶され、ログアウト後もパスワードなしで再ログインできます（マイページで記憶を消せます）。
- マイページでユーザー名・パスワードを変更できます。管理者はユーザー追加・プロジェクト参加・バックアップ操作もここで行います。
- アカウント情報は `scenario-data/.local/auth.json`（Git管理しない）。プロジェクトのデータは `scenario-data/projects/<ID>/` にあり、Gitで管理します。
  - `project.json` / `scenarios/` / `chapters/`（各章に所属シナリオ `sc`）/ `dictionary/` / `users/<ユーザー名>/` / `images/`。自分の書き込みは自分のフォルダにだけ書かれるので競合しにくい設計です。
  - 以前のデータ（シナリオ導入前）は、起動時に自動でシナリオ「本編」へまとめられます（その直前にバックアップを取ります）。
  - プロジェクトを削除すると `scenario-data/.trash/` に退避されます。

## 自動バックアップ（7日ローテーション）
- 起動中は毎日1回（データが更新されていれば同じ日も6時間おきに作り直し）、全プロジェクト＋アカウント情報を `scenario-data/.local/backups/backup-YYYY-MM-DD.zip` に保存し、**新しい7つだけ**を残して古いものを自動削除します。
- 管理者はマイページで一覧・ダウンロード・「今すぐバックアップ」ができます。復元は zip を展開して `projects/` を置き換えます。
- PCを起動しない日は作られません（日数ではなく世代数で7つ残ります）。

## 編集画面
- 左に **ツールボックス**（アイコン）、上に **選んだツールの設定バー**（色・太さ・線の種類など）、右に表示・書き込み・検索のパネル（☰で開閉）。ページ操作（用紙の縦横・書字方向・背景・コンテ枠・改ページ解除）は、各ページの**右の外側**に並びます。
- 画面全体はスクロールせず、**ページ領域だけ**がスクロールします。
- 右パネルの「メモ欄の罫線を表示」で、演出メモ欄の罫線を表示/非表示にできます（この端末に記憶。PDFでは出力時に選べます）。

## 話者の印鑑・セリフのマーカー
- 「話者（印鑑）」ツールでセリフ（または印鑑）をクリックして話者を選ぶと、**横書きは本文の左の余白、縦書きは上の余白**に、そのキャラクターの印鑑が入ります（PDFにも出ます）。
- 印鑑の **色はキャラクターの色**（「キャラクター」タブで設定）か、全員同じ色を選べます。印鑑の文字は名前の頭文字が初期値で、キャラクターごとに変更できます。**形（丸・二重丸・角丸四角・四角・楕円・六角形）・塗り（枠のみ・塗りつぶし・淡い塗り）・文字の並び（縦/横）・文字数・大きさ**を変えられ、キャラクターごとに形・塗りを上書きもできます。文字は印鑑の真ん中に合わせて描画されます（SVG）。
- セリフの **黄色のマーカー**は、右パネルの「🖋 印鑑・マーカー設定」でなくす・色を変えられます。設定は「自分の表示に保存」（あなたのアカウントに保存。どの端末でも同じ）か、編集権限があれば「プロジェクトの標準にする」（全員に反映）で保存します。
- 縦書きの印鑑は、上の余白に収まる大きさ（2文字まで）になります。同じ行（縦書きは同じ列）に複数のセリフがある場合は、最初のセリフの印鑑だけが入ります。

## ボイスドラマ・ASMR台本向けの機能
上の **🧰 台本ツール** ボタン（プロジェクトページにも同じ入口）から開けます。
- **文字数・読み時間**: 章／シナリオ／プロジェクト全体で集計（右パネルとプロジェクトページにも表示、CSV保存可）。仮名1文字=1拍、漢字≒1.8拍、ルビがあれば読みで数え、「、」「。」などの間と `（間3秒）` を加算します。速さ（拍/秒）・句読点の間・地の文を含めるかは設定で変更（自分の表示／プロジェクトの標準）。キャラクターごとの速さ％は「キャラクター」タブで指定。
- **間の表記**: 本文に `（間3秒）`（`（間）`は1秒）と書くと、ページ上で目印として表示され、読み時間に入ります。本文タブの「間を入れる」で挿入。
- **ASMR専用ラベル**: 「演出ラベル」の一覧に「ASMR専用」（耳元・左耳・右耳・ささやき・吐息・耳かき・距離・移動 など）を追加。
- **収録メモ**: 道具箱のマイクのアイコンでセリフをクリック → 状態（録音済み／OK／リテイク）・テイク番号・メモ。セリフの上にバッジが付き、セリフCSVにも出ます（自分のレイヤーに保存、複数人なら新しい記録が優先）。
- **音源リンク**: 演出ラベルを選ぶと右パネルに音源欄。https URL か、アップロードした音声ファイル（`projects/<ID>/audio/` に保存、Range再生対応）。ラベルに ♪ が付き、「音源一覧」で未設定のBGM/SEを探せます。
- **話者別セリフシート**: キャラクターごとにセリフだけの表をPDF／CSVで出力（前後の地の文・ルビ併記・時間・収録欄を選択）。
- **指示一覧**: 文字ボックス・演出ラベルを一覧化。未対応のみ／書いた人／種類／未解決コメントで絞り込み、クリックでその場所へ移動、「対応済み」の切替、CSV保存。
- **コメント**: 道具箱の「コメント」で書き込みをクリック（または右パネルの「💬 コメント」）→ スレッド。解決済み／再開、自分のコメントの削除。閲覧のみの権限では読むだけです。
- **版履歴**: 章を保存するたび（5分以上あいた最初の保存時）に直前の状態を `projects/<ID>/history/<章ID>/*.hist` に自動保存（自動分は新しい80件）。名前付き保存、選んだ版と現在の差分表示、「この版に戻す」（編集権限）。章の削除前の状態も残ります。書き込み（手書き）は対象外です。

## v5 の追加機能（台本全般で使える機能）
- **ボイス・ASMR機能のオン/オフ**: プロジェクトページの「この台本の使い方」（または 🧰 台本ツール）のスイッチ。オフにすると、読み時間・収録メモ・音源リンク・ASMR専用ラベル・キャラクターの速さ・「間を入れる」を画面から隠します（書き込んだデータは消えず、オンに戻せば元通り）。編集権限のある人が切り替え、全員に反映されます（`project.json` の `look.vo`）。
- **話者・収録メモが外れない**: セリフの文言を書き換えたり、前のセリフを増減したりしても、話者の指定・収録メモは新しい文言に追従します。章ファイルに「キー対応表 `rl`」を残し、各ユーザーの記録を読み込み時に読み替える仕組みなので、他の人の記録ファイルは書き換えません。また `ミナト「おはよう」`／`ミナト：「おはよう」` のようにセリフの直前にキャラクター名があれば、自動で話者として扱います（印鑑を手で指定すればそちらが優先）。
- **台本形式の取り込み**: 🧰 → 「台本形式の取り込み」。`ミナト：おはよう` の台本を貼る（txtも可）と、`「おはよう」` に整形し、話者を自動指定、未登録のキャラクターは新規登録（ト書き・場所などは地の文に）。新しい章として、または既存章の末尾に追加。名前を本文に残す形（`ミナト「おはよう」`）も選べます。
- **指示の進行状況**: 章別／担当者別／種類別／書いた人別の進み具合（済/全・未対応・未解決コメント）。行をクリックでその条件の指示一覧へ。文字ボックスを選ぶと右パネルに「担当」欄があり、指示一覧でも担当で絞り込めます。プロジェクトページ上段にも全体の進み具合を表示。
- **キューシート**: 「BGM：雨音」「SE：ドア」「照明：…」のように `種類：内容` で書いた指示を、台本の順にNo.付きで表にします（位置＝いちばん近いセリフ番号。ボイス機能オンのときは章内の時間も）。種類で絞り込み／種類ごとにまとめる／PDF／CSV。
- **セリフ番号**: 「🖋 印鑑・マーカー設定」の「セリフ番号」で、章ごと or シナリオ通しの番号をセリフの頭に表示（PDFにも出ます）。話者別セリフシートやキューシートの番号と一致します。
- **検索・置換（全章まとめて）**: 範囲（章／シナリオ／全体）・対象（全文／セリフだけ／地の文だけ）・正規表現。置換前に変わる様子を確認し、チェックした箇所だけ置換。置換前の状態は各章の版履歴に「置換前」として残ります。
- **前回から変わったところ**: 他の人が本文を更新した・書き込みやコメントが増えた章に「更新」印、プロジェクトページに一覧、章を開いたときにバナーを表示（「すべて既読にする」あり。既読の記録はあなたのアカウントにサーバー保存）。本文の更新者・時刻はサーバーが章ファイルの `upd`/`upby` に記録します。
- **削除した章を戻す**: 削除前の本文が版履歴に残っている章を、元のシナリオ（または別のシナリオ）に復元（編集権限が必要）。他の人の書き込みファイルが残っていれば一緒に戻ります。
- **マイページ**: ヘッダー付きのカード型に刷新（アカウント／表示・この端末／ユーザー管理／バックアップ のタブ。テーマはカードで選択）。

## ページのレイアウト
- 章ごとの既定（本文タブ）と、ページごとの指定（各ページ下のボタン）で、用紙の **縦/横**・**横書き/縦書き**・**メモ欄(コンテ枠)の有無** を切り替えられます。縦書きではメモ欄が下に来ます。
- 本文中の改ページ行 `--- 横向き 縦書き 背景=blueprint 文字色=#ffffff *` がページ指定です（ボタン操作で自動で書き換わります）。
- 背景デザイン(標準・単色・ブループリント・モダン・方眼紙・和紙・ナイト・ドット)と本文の文字色を、章ごと・ページごとに指定できます。
- 表示は「全ページ(スクロール)」と「1ページずつ」を切り替えられます。
- ルビは `｜漢字《かんじ》` または `漢字《かんじ》` と書きます（文字ボックスの中でも使えます）。

## 画像
`🖼画像` → アップロード（`projects/<ID>/images/` にコピー）、または「サーバーから選ぶ」（コピーせず相対パスだけ保存）。
サーバー上の場所を選べるのは編集権限のユーザーだけです。範囲を絞るなら `--image-base フォルダ`。

## PDF
- **プロジェクト全体**: プロジェクトページ上部の「📄 プロジェクト全体を1つのPDFにする」で、全シナリオの章を1つのPDFにします（プロジェクト表紙・シナリオごとの扉・設定資料・メモ罫線を選べます）。各シナリオ内でチェックした章だけが入り、PDF出力を許可されていないシナリオは含まれません。
- **シナリオ単位**: プロジェクトページの **各シナリオのツールバー**（または編集画面の「📄 PDF」）から、そのシナリオの選んだ章をまとめてPDFにします。表紙・設定資料・メモ罫線の有無を選べます。印刷画面で送信先「PDFに保存」、用紙A4・余白なし・背景のグラフィックON。縦横が混在していても1つのPDFになります。PDF出力を許可されていないシナリオではボタンが無効になります。

## 表示テーマ（ライト / ダーク）
ログイン画面・一覧・編集画面の上部にある選択欄で「端末に合わせる / ライト / ダーク」を切り替えられます（あなたのアカウントに保存。ログイン前は端末の設定に合わせます）。

## ペンタブ / iPad
ペン(Apple Pencil・液タブ)で描き、指はスクロール/ピンチ。指でも描くときは「指でも描く」をON（ペンが使えないスマホでは最初からON）。ONのときは、**2本指のスワイプでスクロール、ピンチで拡大縮小**できます。ペンを付けている間の手のひらの接触は無視されます。ペンの消しゴム端で消せます。

## v6: ブラウザにデータを保存しない / ユーザーごとの設定 / アイコン・帯の色
- **ブラウザのローカルストレージ・セッションストレージ・IndexedDB は一切使いません**（ログインの記憶はサーバーが発行するCookieのみ）。
- 見た目などの設定は、**ユーザーごとにサーバーへ保存**します（`scenario-data/userdata/<ユーザー>/prefs.json`）。保存されるもの: 表示テーマ、右パネルの開閉、メモ欄の罫線、マイページの帯の色、プロジェクトごとの「自分の表示」（印鑑・マーカー設定）、読み時間の設定、更新の既読の記録。別の端末・別のブラウザでも同じユーザーなら同じ状態で開きます。ログイン前の画面は端末の設定（ライト/ダーク）に従います。
- **アイコン画像**: マイページ「アカウント」→「画像を選ぶ」。切り抜き（拡大・左右・上下）で正方形にして保存（PNG/JPEG/WebP/GIF、700KBまで。`userdata/<ユーザー>/avatar.*`）。右上・マイページ・ユーザー一覧に表示。画像を外すと頭文字に戻ります。
- **マイページの帯の色**: 色見本9種＋自由に2色（はじめ→おわり）。明るい色の帯では文字色が自動で濃くなります。
- API: `GET/PUT /api/prefs`（自分の設定。`{"set": {キー: 値}}` で部分更新、値 `null` で削除）、`GET /api/avatar?u=ユーザー`、`POST /api/avatar`（本文=画像）、`DELETE /api/avatar`。
