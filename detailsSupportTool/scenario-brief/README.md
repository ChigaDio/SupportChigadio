# シナリオ演出依頼資料集

## 起動
- Windows: `run.bat` をダブルクリック / Mac・Linux: `./run.sh`（Python 3.8+、追加インストール不要）
- ブラウザが自動で開きます。初回は「表紙」でプロジェクト名、上部で自分の名前を入力。
- 保存先は `scenario-data/`（`--data パス` で変更可）。このフォルダをGitで管理します。
  - `project.json` / `chapters/` / `dictionary/` / `users/<名前>/` に1ファイルずつ保存。自分の書き込みは `users/<自分の名前>/` だけに書かれます。
  - `scenario-data/.local/`（自分の名前）は `.gitignore` 済み。
- `git pull` のあとは画面上部の「🔄 再読込」。

## 実行ファイル化 (PyInstaller)
- `build.bat`（Windows） / `./build.sh`（Mac）→ `dist/ScenarioBrief(.exe)`
- 各OS上でビルドしてください（クロスビルド不可）。exeと同じ場所に `scenario-data/` が作られます。

## PDF
「📄 PDF出力(A4)」→ 印刷画面で送信先「PDFに保存」、用紙A4・余白なし・背景のグラフィックON。

## 画像
`🖼画像` / Ctrl+V貼り付け / ドラッグ&ドロップ → `scenario-data/images/<ハッシュ>_<名前>.png` に保存し、JSONには相対パス `images/…` だけを書きます（同じ画像は同じファイル名になるので競合しません）。画像もGitに含めてください。

## 起動してもページが開かない / 空の応答になる
- 黒いコンソール窓に出ている URL（ポート番号）を開いてください。8765が使用中なら 8766… に自動で切り替わります。
- 前に起動したままの窓（python / ScenarioBrief）が残っていたら閉じてください（タスクマネージャーで終了）。
- エラー内容はブラウザ画面とコンソールの両方に表示されます。

## 画像ライブラリ(相対パス) / 消しゴム / タッチ
- 🖼画像 → 「サーバーから選ぶ」でエクスプローラー風の画面が開きます（フォルダを辿り、画像をクリックして選択）。選んだ場所は **コピーせず**、データフォルダからの相対パス(例 `../art/a.png`)だけを `project.json` の `imgRefs` に保存します。サーバー上のどこでも選べます（`--image-base フォルダ` で範囲を制限することも可）。
- 「再読込」で画像ファイルの更新を取り込みます。
- 消しゴムは「部分消し(ペイント風)」が既定。大きさは太さスライダーです。
- iPad/液タブ: ペンで描き、指はスクロール/ピンチ。指でも描く場合は「指でも描く」をON。

## 他のPC / iPad から使う
- 起動すると、黒い画面に `http://192.168.x.x:8765/?key=…` のようなURLが出ます。同じWi-Fi/LANの端末でそのURLを開いてください（初回だけ。以後は端末に記憶されます）。
- アクセスキーは `scenario-data/.local/key.txt` に保存され、起動のたびに同じです（`--key 好きな文字列` で変更可）。キーを知らない端末は開けません。
- 自分の名前は **端末ごと** に覚えます（端末が変わったら入力し直し）。同じ名前を複数の端末で同時に使うと、その人の書き込みファイルが上書きされ合うので、端末ごとに別の名前にしてください。
- 他の端末の変更は数秒おきに自動で反映されます。
- このPCだけで使うなら `--local-only`。Windowsでは初回にファイアウォールの許可を求められます（プライベートネットワークを許可）。
- 注意: キーを知っている端末は、画像ライブラリからサーバー上の画像ファイルを辿れます。範囲を絞るなら `--image-base フォルダ`。
